# SiteForge — AI Website Builder

AI-assisted visual website builder with editable sections, live desktop/mobile preview and HTML export.

Live demo: https://siteforge-ai-website-builder-lks8eq.v2.appdeploy.ai/

## Run locally

```bash
npm install
npm run dev
```

The AI generation endpoint uses AppDeploy's backend SDK and requires the matching AppDeploy runtime/configuration when deployed outside the original environment.
